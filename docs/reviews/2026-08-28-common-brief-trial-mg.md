# Cross-Plugin Common Brief Trial — MG Track

This is an MG-only comparison experiment. No output from illustrated-metaphor or handdrawn-animation was inspected.

| Brief | Suitability | Existing grammar / variant | Reason |
| --- | --- | --- | --- |
| CB01 Core Judgment | SUITABLE | thesis | Editorial headline establishes a single judgment quickly. |
| CB02 Causal Transmission | SUITABLE | causal-flow / pressure-transfer | Propagation is native to the grammar. |
| CB03 Accumulation Pressure | SUITABLE | layered-metaphor / accumulation | Layering and threshold structure are natural MG work. |
| CB04 Feedback Loop | SUITABLE | cycle / positive-feedback | Return path and looping rhythm communicate the mechanism. |
| CB05 Two-side Tension | SUITABLE | relationship-map / tension | Weighted opposing links give the relation priority over node count. |
| CB06 Surface vs Mechanism | SUITABLE | layered-metaphor / hidden-mechanism | Surface/underlying structure is a direct spatial explanation. |
| CB07 Rule Change | SUITABLE | editorial-timeline | Temporal segmentation is clearer than adding a new grammar. |
| CB08 Numeric Evidence | SUITABLE | delta-metric | Metric change can remain subordinate to the causal judgment. |

All eight are suitable without a new renderer, profile, grammar family, or architecture workaround. Review after renders evaluates clarity, timing, density, distinctiveness and creator usefulness per brief.
