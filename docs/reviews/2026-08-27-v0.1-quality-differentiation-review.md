## Four grammar findings

- **Causal:** propagating pressure has a meaningful direction and a late, emphasized outcome. It is still a single linear causal chain; branching and delayed parallel effects are V0.2 candidates.
- **Cycle:** the red return path creates an explicit feedback reading. The next improvement should encode positive/negative feedback strength rather than only return direction.
- **Relationship:** link weight and node prominence now communicate influence. It still represents only a compact three-peripheral-node structure and does not yet encode conflict/tension states.
- **Abstract:** the threshold separates visible results from supporting layers, making “accumulation” inspectable. Bottleneck and constraint variants remain to be benchmarked.

## Template reduction

The profile remains recognizably editorial through its palette, typography, safe area, and restrained accent. V0.1 replaces one universal top-left-title composition with deliberate anchors: left rail for causal/relationship, centered top for cycle, bottom-left for abstract/delta, and retained top-left thesis where appropriate. This is meaningful variation without random placement or unrelated templates.

## Adversarial typography results

The independent suite covers long Chinese judgment, multiline Chinese, narrow region, dense numbers, percentages/units, Chinese-English-number mixing, long label, and multi-layer hierarchy. Seven bounded readable cases preserve all source characters. One 43-character display judgment is intentionally rejected because it exceeds the two-line display capacity; a 20-repeat label rejection is also verified. No fixture is silently truncated, overlapped, or shrunk below the role's readable capacity.

## Human visual verdict

V0.1 passes its Quality Differentiation objective for the four target grammars. It materially improves meaning-bound composition and motion while retaining a single editorial design system. It does not yet prove viewer comprehension, editor preference, cross-machine font reproducibility, real-episode usefulness, or the need for a high-impact profile.

## User aesthetic choice

None required. The comparison has a clear directional result and does not create a product-level visual ambiguity.
